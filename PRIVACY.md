# Privacy Policy for Youtube Transcript button

Effective date: October 11, 2026

## What the extension does

Youtube Transcript button adds a button to YouTube video pages that opens YouTube's existing transcript panel.

## Information accessed and used

The extension processes the current YouTube page URL and page elements locally in your browser to identify video pages, position the button, locate YouTube's transcript controls, and detect navigation between videos. This information is used only to provide the transcript shortcut.

## Collection, storage, and sharing

The extension does not collect or transmit personal information to the developer or third parties. It does not save browsing history, video URLs, transcript content, or user identifiers. Temporary page state exists only in browser memory while the extension operates.

The extension contains no analytics, advertising, tracking tools, cookies, or external servers. It does not sell or share user data.

## YouTube access

The extension runs only on https://www.youtube.com/* because it needs to add the shortcut and activate YouTube's own controls. Opening a transcript uses YouTube's normal functionality. YouTube's own processing of information is governed by Google's privacy policy; this policy describes the extension itself.

## Changes

This policy will be updated if the extension's privacy practices change.

## Contact

For privacy questions, contact the publisher through the support contact provided on the extension's Chrome Web Store listing.
